# Community expectations

Help make this project useful and welcoming. Be respectful, focus criticism on the technical work, and make space for contributors with different backgrounds and experience.

Harassment, personal attacks, threats, discriminatory abuse, disclosure of private information and deliberately misleading benchmark submissions are unacceptable. Do not post credentials, private datasets or model weights you cannot redistribute.

Keep issues and pull requests relevant and reproducible. Explain uncertainty, disclose changes to the comparison setup and credit upstream work.

Maintainers may remove harmful content, close off-topic threads or restrict participation when needed. Use a redacted issue requesting a private channel for a sensitive conduct concern; do not repeat personal information publicly.
